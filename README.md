# ZENEX – AI Coding Assistant
ZENEX is an AI-powered coding assistant built with React, FastAPI, Python, and Google Gemini. It supports code generation, debugging, explanation, review, optimization, file analysis, RAG, secure authentication, and MySQL chat history.
ZENEX – AI Coding Assistant

Overview

ZENEX is an AI-powered coding assistant designed to simplify software development by providing intelligent coding support through Google's Gemini models. It offers a modern, user-friendly interface that helps developers improve productivity, understand code, and solve programming problems efficiently.

Features

Code Generation: Generate code using natural language prompts.

Code Debugging: Identify programming errors and suggest solutions.

Code Explanation: Understand complex code through clear explanations.

Code Review: Analyze code quality and identify improvements.

Code Optimization: Improve code efficiency and performance.

Test Generation: Generate test cases for existing code.

Code Conversion: Convert code between programming languages.

File Analysis: Upload and analyze supported files.

Model Selection: Choose between available Gemini models.

Automatic Fallback: Automatically switch models when necessary.

RAG Integration: Retrieve relevant information from knowledge sources.

Authentication: Secure login and registration using JWT.

OAuth Integration: Support Google and Microsoft authentication.

Password Recovery: Forgot password and password reset functionality.

Chat History: Store conversations and messages using MySQL.

Microphone Support: Enable voice input for interacting with the assistant.

Technology Stack

Frontend: React.js, Vite, JavaScript, CSS
Backend: Python, FastAPI, Uvicorn
AI: Google Gemini API, Gemini Embeddings
Database: MySQL, SQLAlchemy
Authentication: JWT, Google OAuth, Microsoft OAuth
Testing: Pytest
Version Control: Git, GitHub
